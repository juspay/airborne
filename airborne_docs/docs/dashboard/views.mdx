A **View** is a saved [dimension](/docs/dashboard/dimensions) filter. Rather than reconstructing the same set of dimension values every time you want to inspect a particular audience, you save them once as a named View and reuse it to slice your [releases](/docs/dashboard/releases) by that segment.

Views come in two types:

| Type | Where it comes from |
| --- | --- |
| **Custom** | You created it, from **Create View**. |
| **Auto-generated** | Airborne created it when a release was created, from that release's dimensions. |

## The Views page

The page lists every saved view with a **Custom** or **Auto-generated** badge and the dimension filters it captures shown as `key: value` badges. Click a view to expand it and see the release information for that filter. Use the **Filter by type** control to narrow the list to one type.

Custom views have **Edit** and **Delete** actions. Auto-generated views have only **Delete** — their name and filter mirror a release's dimensions, so editing them would make them lie about where they came from. To keep a modified version, create a custom view instead.

## Creating a view

Choose **Create View**. In the **Create a new view** dialog:

- Enter a **View Name**. It is normalised to snake_case (lowercase, spaces become underscores).
- Add one or more **Dimensions**. Each row pairs a **Dimension** (chosen from your defined dimensions) with a **Value**. Use **+ Add Dimension** to add more rows and the remove control to drop one. At least one dimension is required.

Choose **Create View** to save it.

## Auto-generated views

Every time a release is created, Airborne saves a view for that release's dimensions, so each slice you have ever shipped to is browsable without rebuilding the filter by hand.

- **Name** — the release's dimensions sorted by key and joined as `key=value`, for example `city=blr, os=android`. A release that targets no dimensions produces a view named `default`.
- **No duplicates** — if a view (of either type) already covers that exact set of dimension values, no new view is created. The dimension order does not matter for this comparison.
- **Delete freely** — deleting an auto-generated view does not affect the release. If a later release targets the same dimensions again, the view comes back.

:::note
Auto-generated views appear only for releases created after this feature shipped — existing releases are not backfilled.
:::

## Using views

Once saved, a view captures "show me the releases that match these dimension values." Expanding a view surfaces the release information for that slice, so you can quickly answer questions like "what's currently shipping to this segment?" without rebuilding the filter each time.

:::tip
Create a custom view for each audience you care about — for example a region, a platform, or a beta [cohort](/docs/dashboard/cohorts) — so anyone on the team can check that segment's releases at a glance.
:::
